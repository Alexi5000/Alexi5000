# Support and contact

For questions about a public project, collaboration, or a correction to this profile, start at [techtideai.io](https://techtideai.io) or email [alex@techtideai.io](mailto:alex@techtideai.io). Include the relevant repository or profile section, the goal of the request, and enough context to reproduce a documentation issue.

| Request | Best route |
| --- | --- |
| Public profile correction or project question | Open a focused issue or email [alex@techtideai.io](mailto:alex@techtideai.io). |
| Collaboration or services inquiry | Visit [techtideai.io](https://techtideai.io). |
| Contribution proposal | Read [CONTRIBUTING.md](./CONTRIBUTING.md) and open a pull request with validation evidence. |
| Security-sensitive information | Follow [SECURITY.md](./SECURITY.md); do not use a public issue. |

Do not post credentials, client records, private repository content, payment details, or other confidential material in public discussions.
