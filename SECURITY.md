# Security policy

Please do not report security vulnerabilities, exposed credentials, or sensitive privacy concerns in a public issue, pull request, or profile comment.

Send a concise report to [alex@techtideai.io](mailto:alex@techtideai.io) with the subject line `Confidential: security report`. Include the affected public project or profile asset, a clear description of the concern, and only the minimum evidence needed to understand it. Do not include credentials, customer data, or exploit instructions in public channels.

This profile repository contains public documentation and visual assets. Security concerns affecting a linked project should be reported according to that project’s own security policy when one is available.
