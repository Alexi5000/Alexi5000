# Contributing to the Alexi5000 profile

This repository is the public source for the Alexi5000 GitHub profile. Contributions should keep the profile accurate, intentional, and safe to publish.

Before proposing a change, run the repository contract from the project root:

```bash
npm ci
npm run build
npm run lint
npm run typecheck
npm test
```

Use focused updates. New project entries should include a stable public destination, a concise description that can be substantiated, and only assets that are approved for public use. Do not add credentials, client data, unpublished product details, private repository links, or screenshots containing sensitive information.

For significant wording, positioning, or asset changes, open a pull request that explains the user-facing intent and identifies the profile sections affected. Participation is governed by the [Code of Conduct](./CODE_OF_CONDUCT.md).
